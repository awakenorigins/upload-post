# upload-post — Post to 10+ social platforms via one API

> Publish videos, photos, text, and documents to TikTok, Instagram, YouTube, LinkedIn, Facebook, X/Twitter, Threads, Pinterest, Reddit, and Bluesky. Supports scheduling and analytics.

[![OpenClaw Skill](https://img.shields.io/badge/OpenClaw-Skill-blueviolet)](https://github.com/NachaFromMars)

## Overview
upload-post integrates with the Upload-Post API to publish content to 10+ platforms in a single call. Connect accounts via dashboard, create a Profile, get an API key. Supports scheduling, analytics, FFmpeg processing, and upload history.

## Features
- 10+ platforms: TikTok, Instagram, YouTube, LinkedIn, Facebook, X/Twitter, Threads, Pinterest, Reddit, Bluesky
- Content types: videos, photos, text, documents
- Scheduling, analytics, FFmpeg processing, upload history

## Usage / Quick Start
```
Authorization: Apikey YOUR_API_KEY
Base URL: https://api.upload-post.com/api
Docs: https://docs.upload-post.com
```
